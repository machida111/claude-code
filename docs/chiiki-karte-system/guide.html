指標の計算方法とデータについて

地域課題マップ・市町村カルテで表示している8つの課題指標が、どのデータからどう計算されているかをまとめたページです。判断材料として使う前に、実データに基づく部分と簡易的な推定の部分の違いを確認してください。

Overview

このツールでできること

地域課題カルテは3つの画面から構成されています。いずれも表示専用で、統計データは事前に埋め込まれています。

01

地域課題マップ

大阪府43市町村を8指標のいずれかでコロプレス表示。行政区域境界（国土数値情報）を地理院タイル上に塗り分けます。

02

市町村カルテ

市町村ごとの基礎情報と8指標のレーダーチャート。担当者メモをブラウザに保存できます。

03

分析レポート

全域／地域ブロック／市町村を指定し、指標スコアから共通課題・支援方針をルールベースで文章化します。

1 · Data sources

元になっているデータ

指標の入力に使っている値はすべて公的統計・地理データです。年次はデータソースの最新公表年に依存します。

2 · Scoring

8つの課題指標の計算方法

各指標は1〜5の整数スコア（5が最も課題が大きい）。「実データ」は上記の統計値を直接計算に使っているもの、「推定」はその統計値を使った簡易的な代理指標で、その課題を直接測った統計そのものではないものです。

1 : 小さい 2 3 4 5 : 大きい

人口減少

実データ
入力：人口増減率（2015→2020年の年率換算）

増減率が低い（減少が大きい）ほど高スコア。増減率0%を基準の3点付近に置き、傾き1.1倍で振れを反映します。

score = 3 − 人口増減率(%) × 1.1 ＋ 補正値

高齢化

実データ
入力：高齢化率（65歳以上人口比率）

高齢化率15%を基準点として、5.5ポイントの差を1点分の変化として換算します。

score = (高齢化率(%) − 15) / 5.5 ＋ 補正値

空き家

推定
入力：「人口減少」「高齢化」スコア（空き家率の実データは未使用）

人口減少と高齢化が進むほど空き家も増えやすいという前提で、両スコアの平均から推定しています。

score = 人口減少スコア×0.5 ＋ 高齢化スコア×0.5 ＋ 補正値

公共交通

推定
入力：人口密度（人口÷面積、実データから算出）

密度が低いほど路線・便数を維持しにくいとみなし、密度の対数が小さいほど高スコアにしています。

score = 6 − log10(人口密度) ＋ 補正値

地域コミュニティ

推定
入力：「人口減少」「高齢化」スコア（自治会加入率等の実データは未使用）

人口減少・高齢化が進む地域では担い手が減り活動が弱まりやすいという前提の代理指標です。

score = (人口減少スコア ＋ 高齢化スコア) / 2 ＋ 補正値

担い手不足

推定
入力：高齢化率、財政力指数（いずれも実データ）

高齢化の度合いを主要因（60%）に、財政力の低さ（自主財源の乏しさ）を補助要因（40%）として合成しています。

score = 高齢化スコア×0.6 ＋ (1−財政力指数)×3×0.4 ＋ 補正値

防災

推定
入力：地域ブロック、人口密度（ハザードマップ等の実データは未使用）

地域ブロックごとに設定した基準値（沿岸部・山間部を含む泉南・南河内地域などをやや高めに設定）に、人口密度が低い地域への補正を加えています。

score = 地域ブロック基準値（低密度地域は+0.5）＋ 補正値

DX（行政デジタル化の遅れ）

推定
入力：財政力指数、人口密度（いずれも実データ）

財政力が低く、人口密度が低い（≒ICT投資の原資や規模の経済が得にくい）市町村ほど高スコアにしています。

score = 4.2 − 財政力指数×2.4 − log10(人口密度)×0.15 ＋ 補正値
!

「＋ 補正値」について — 各スコアには、市町村名を種（シード）にした小さな補正値を加えています。これは人口構造が似た市町村同士が完全に同じスコアになって見分けがつかなくなるのを避けるための演出であり、追加の統計データを反映したものではありません。同じ市町村・同じ指標であれば常に同じ値になります（ページを開き直しても変わりません）。

3 · Composite score

総合スコアの算出

地図の「総合」表示やカルテのレーダーチャートで使う総合スコアは、8指標の単純平均です。重み付けはしていません。

総合スコア = (人口減少 + 高齢化 + 空き家 + 公共交通 + 地域コミュニティ + 担い手不足 + 防災 + DX) / 8
4 · Caution

利用上の注意

!

8指標のうち「人口減少」「高齢化」は実データ（人口増減率・高齢化率）から直接計算していますが、残り6指標（空き家・公共交通・地域コミュニティ・担い手不足・防災・DX）は、人口・面積・財政力指数などの実データを使った簡易的な推定モデルです。空き家率や避難所整備状況、ICT投資額といった、その課題を直接表す統計そのものは使用していません。

そのため、このスコアは市町村間の傾向を大まかに掴むための参考情報であり、公式な統計指標や評価結果ではありません。個別市町村の政策判断に用いる際は、現場の実態確認や関連部署へのヒアリングと合わせて利用してください。
