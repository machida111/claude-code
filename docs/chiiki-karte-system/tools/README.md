# データ更新手順（tools/）

`app.html` に埋め込んでいる統計値を作り直すためのスクリプトです。新しい年度のデータが公表されたら、
ここの手順で数値を作り直し、`app.html` の該当する変数を置き換えます。

## 準備

```bash
cd docs/chiiki-karte-system/tools
pip install -r requirements.txt   # numpy, shapely>=2.0, pyshp, openpyxl
./download.sh                     # 地理データ・公開ファイルを tools/data/ に取得（展開後 約500MB、APIキー不要）
```

`data/` と `out/` はダウンロードしたデータ・計算結果の置き場で、リポジトリには入れません（`.gitignore`）。

## スクリプトで作り直せるデータ

各スクリプトは `out/*.json` に結果を保存し、`app.html` にそのまま貼れる形の JavaScript を画面に出力します。

| スクリプト | 作る変数（app.html） | 入力 | 所要時間 |
|---|---|---|---|
| `estat.py` | `CAR_COMMUTE_RATE`（公共交通）<br>`WORK_AGE_CHANGE`（担い手不足）<br>`AGING_RISE`・`ESTABLISHMENTS`（分析レポートの「変化」）<br>`ELDERLY_HOUSEHOLDS`（カルテの参考値） | e-Stat API（国勢調査「利用交通手段」0003454514、社会・人口統計体系 0000020201・0000020203） | 数十秒 |
| `geo.py` | `FLOOD_EXPOSURE`（水害）<br>`QUAKE_HAZARD`（地震の揺れ・液状化）<br>`RAIL_COVER_1KM`（カルテの参考値）<br>`ADJACENT`（隣接市町村） | 国土数値情報 A31a・A49・A40・N02、J-SHIS 地震動予測地図・微地形区分、国勢調査250mメッシュ人口 | 約3〜4分 |
| `dx.py` | `DX_ADMIN`（DX） | 総務省 AI・RPA・生成AI導入状況調査、自治体DX・情報化推進概要 個別資料 | 数秒 |

```bash
ESTAT_APPID=<アプリケーションID> python3 estat.py
python3 geo.py
python3 dx.py
```

**e-Stat のアプリケーションIDは、ファイル・コミット・チャットに書かないでください。** e-Stat のマイページで
発行したIDを、上のようにコマンドの環境変数としてだけ渡します。

### 年度を更新するとき

- 国土数値情報：`download.sh` の版番号（`A31a-24`、`N02-23` など）を新しい版に書き換える。
  浸水想定区域の属性（`A31a_205` の浸水深ランク、`A49_003`、`A40_003`）の定義が変わっていないか、
  国土数値情報の各ページで確認する。
- J-SHIS：`download.sh` の `Y2024` を新しい版（`Y2025` など）に書き換える。
- 国勢調査：2025年調査の250mメッシュが公表されたら、`download.sh` の `S002005112020` を新しい調査IDに、
  `estat.py` の統計表ID・`cdTime` を新しいものに書き換える。
- 総務省のDX関連調査：`download.sh` の `main_content/0010xxxxx` を新しいファイルに書き換える。
  Excel の列の位置が変わることがあるため、`dx.py` の冒頭に書いた列番号を確認する。

作り直したら、アプリ内の説明文（「指標の計算方法」画面）に書いてある例示の数値（「門真市96.5%」など）も
新しい値に合わせて直してください。

### 照合

作り直した値と `app.html` の現在の値を比べると、手順の誤りに気づけます。2026年9月時点では、
`geo.py`・`dx.py`・`estat.py` の出力は `app.html` の値と一致します。

## 手作業で更新するデータ

次のデータは、公表形式（PDF・Webページ・都度形式が変わるExcel）の都合でスクリプト化していません。
`app.html` の変数を直接書き換えます。

| 変数 | 内容 | 出典 |
|---|---|---|
| `RAW` | 人口・人口増減率・高齢化率・面積・世帯数・財政力指数・空き家率・65歳以上単独世帯率・マイナンバーカード保有率・土砂災害警戒区域数 | e-Stat 社会・人口統計体系、総務省（地方財政状況調査・住宅・土地統計調査・マイナンバーカード交付状況）、大阪府（土砂災害防止法の指定状況） |
| `RESIDENT_RAW` | 食料品アクセス困難人口割合・可住地面積当たり診療所数・学校数・可住地面積 | 農林水産政策研究所「食料品アクセスマップ」、e-Stat 社会・人口統計体系、学校基本調査 |
| `NURSING_PER1K` | 介護施設定員（65歳以上千人当たり、カルテの参考値） | 介護保険事業状況報告ほか |
| `RESAS_POP2050` / `RESAS_LEAKAGE` / `RESAS_INDUSTRY` | 将来人口・支出流出入率・業種別事業所数 | RESAS（Webページから取得） |
| `OSAKA_GEOJSON` | 市町村境界 | 国土数値情報 行政区域データ（N03）を簡略化 |

各変数の直前のコメントに、年次と出典を書いています。
