Overview

このツールでできること

地域課題カルテは5つの画面から構成されています。いずれも表示専用で、統計データは事前に埋め込まれています。

01

地域課題マップ

大阪府43市町村を8指標（行政の計画視点）のいずれかでコロプレス表示。行政区域境界（国土数値情報）を地理院タイル上に塗り分けます。

02

住民目線マップ

買い物・医療・学校への行きやすさと地元消費の流出という4指標（住民の生活視点）で同じ地図をコロプレス表示します。

03

市町村カルテ

市町村ごとの基礎情報と、地域課題マップ8指標・住民目線マップ4指標のレーダーチャート。RESASの将来人口・業種別事業所数も参考表示します。

04

分析レポート

全域／地域ブロック／市町村を指定し、地域課題マップ8指標・住民目線マップ4指標のスコアから共通課題・支援方針をルールベースで文章化します（外部API呼び出しなし）。

05

2 · Scoring

8つの課題指標の計算方法

各指標は1〜5の整数スコア（5が最も課題が大きい）。8指標すべて、その課題に対応する公的統計を直接スコア化しています。多くの指標は市町村ごとの実際の値の分布（25パーセンタイル・中央値・75パーセンタイルの近辺がそれぞれ概ね2点・3点・4点になるよう設定）に基づいてスコア化しており、市町村名などによる人為的な補正は加えていません。

1 : 小さい 2 3 4 5 : 大きい

人口減少

実データ
入力：人口増減率（2015→2020年の年率換算）

増減率が低い（減少が大きい）ほど高スコア。増減率0%を基準の3点付近に置き、傾き1.1倍で振れを反映します。

score = 3 − 人口増減率(%) × 1.1

高齢化

実データ
入力：高齢化率（65歳以上人口比率）

高齢化率15%を基準点として、5.5ポイントの差を1点分の変化として換算します。

score = (高齢化率(%) − 15) / 5.5

空き家

実データ
入力：空き家率（令和5年住宅・土地統計調査）

大阪府38市町村の空き家率（中央値13.4%）を基準に、1.6ポイントの差を1点分としてスコア化。人口が少なく調査結果が未公表の5町村（能勢町・田尻町・岬町・太子町・千早赤阪村）は「データなし」として地図をグレー表示し、総合スコアの算出から除外します（推定値による代用はしていません）。

score = 3 + (空き家率(%) − 13.4) / 1.6 未公表の5町村: データなし（総合スコアの算出から除外）

公共交通

実データ
入力：通勤・通学に自家用車を利用する人の割合（2020年国勢調査「利用交通手段」）

公共交通で用が足りる地域では鉄道・バス・自転車・徒歩が選べますが、路線や便数が足りない地域では自家用車に頼らざるを得ません。その割合を、住民が実際に取っている行動として直接測った指標です。中央値27.8%を基準に、11.2ポイントの差を1点分としています。大阪市10.5%（最低）から能勢町75.7%（最高）まで分布します。

score = 3 + (自家用車利用率(%) − 27.8) / 11.2

地域コミュニティ

実データ
入力：65歳以上世帯員の単独世帯の割合（国勢調査）

高齢者の一人暮らし世帯が多いほど、見守りや自治会活動などの地域の担い手が細りやすいとみなしています。自治会加入率のような直接統計は市町村ごとに集計方法が異なり全市町村分をそろえられないため、この指標を代理として使用しています。

score = 3 + (65歳以上単独世帯率(%) − 13.4) / 1.3

担い手不足

実データ
入力：高齢就業者割合（65歳以上、国勢調査）

就業者のうち65歳以上が占める割合。この割合が高い市町村ほど、農業や商店など現場の担い手が高齢層に偏っており、後継者不足のリスクが大きいとみなしています。

score = 3 + (高齢就業者割合(%) − 21.3) / 1.2

防災

実データ
入力：土砂災害警戒区域数（大阪府指定）÷ 面積

面積あたりの土砂災害警戒区域数が多いほど高スコア。市街地中心部（大阪市・守口市・摂津市など）は区域指定がなく0件です。洪水・高潮・地震など他の災害リスクは含まれておらず、土砂災害リスクに限定した指標です。

score = 1 + (土砂災害警戒区域数 / 面積km2) / 2.2

DX（行政デジタル化の遅れ）

実データ
入力：AI・RPA・生成AIの導入状況（総務省、令和7年度）／重点計画対象手続のオンライン化状況（総務省「自治体DX・情報化推進概要」、令和7年4月1日現在）

役所側のデジタル化を2つの面から測り、平均しています。①AI・RPA・生成AIをそれぞれ導入済1点・実証実験中0.5点として合計（0〜3点）し、3点なら1、0点なら5。②図書館予約・粗大ごみ・児童手当・保育・介護・転出入など、国の重点計画でオンライン化を求められている手続のうち「オンライン化済」の割合を、中央値72.5%を基準に17ポイントで1点分としています。住民側の普及率であるマイナンバーカード保有率は、行政のデジタル化の遅れそのものではないため、カルテの参考値に移しました。

導入点 = AI + RPA + 生成AI（導入済1・実証中0.5・未導入0） score = ((5 − 導入点 × 4/3) + (3 − (オンライン化済割合(%) − 72.5) / 17)) / 2
3 · Scoring (resident view)

4つの住民目線指標の計算方法

「住民目線マップ」の4指標はすべて実データです。住民が日常生活で感じる不便さを「行きにくさ」として測っています。値が悪いほど課題スコアが高くなるよう、必要に応じて反転してスコア化しています。

!

なぜ「人口当たりの施設数」を使わないのか。当初は「人口10万人当たりの診療所数」のような供給量の指標で測っていましたが、人口が減った町村ほど見かけ上「1人当たりの施設が多い＝恵まれている」と出てしまい、住民の実感と逆になる問題がありました。たとえば千早赤阪村（人口4,909人）は診療所5軒で「人口10万人当たり102施設」と府内最上位クラスになりますが、実際には村内の移動距離が長く、多くの用事で隣の市町村まで出る必要があります。

そこで指標を「どれだけ施設があるか」ではなく「そこに住んでいる人がどれだけ行きにくいか」に組み直しました。人口を母数から外し、実際に人が住んでいる面積（可住地面積）当たりの施設密度と、国の実測に基づく買い物困難人口の割合を使っています。

買い物の不便さ

実データ
入力：食料品アクセス困難人口割合（65歳以上、農林水産省「食料品アクセスマップ」2020年）

店舗まで直線距離500m以上で、かつ自動車を利用しにくい65歳以上住民の割合。500mメッシュ単位の店舗立地と国勢調査人口から国が算出したもので、施設数ではなく「実際に買い物に困っている人がどれだけいるか」を直接表します。府内中央値29.29%を基準に、6.4ポイントの差を1点分としています。割合が高いほど高スコア（課題が大きい）。

score = 3 + (食料品アクセス困難率(%) − 29.29) / 6.4

医療への行きにくさ

実データ
入力：可住地面積100km²当たり一般診療所数（e-Stat 社会・人口統計体系、2023年／小規模自治体補正済み）

人口ではなく可住地面積を母数にすることで、「近所に医院があるか」に近い密度になります。密度は大阪市（1,657施設/100km²）と能勢町（32.8施設/100km²）で50倍以上開くため、常用対数（log10）に変換してから点数化しています。密度が低いほど高スコア。

score = 3 − (log10(補正後診療所密度) − 2.60) / 0.19

学校への通いにくさ

実データ
入力：可住地面積100km²当たり小学校＋義務教育学校数（学校基本調査、2024年／小規模自治体補正済み）

児童数当たりではなく可住地面積当たりにすることで、「子どもが歩いて通える距離に学校があるか」に近い指標になります。児童数を母数にすると、児童が減って学校を統廃合した町村ほど良い値が出てしまうためです。義務教育学校（小中一体型）に統合済みの町村も小学校相当として合算しています。診療所と同様に対数変換しています。

score = 3 − (log10(補正後学校密度) − 1.81) / 0.14

地元で買えない度

実データ
入力：支出流出入率（RESAS「地域ビジネス環境分析」、2022年）

住民の消費が地域内にどれだけ留まっているかを示す指標。マイナス（域外へ流出）が大きいほど、日常の買い物や飲食を域外に頼っている＝地元で用が足りないことを意味するため、高スコアとしています。中央値-5.6%を基準に、6ポイントの差を1点分としています。データが非公開の市町村（河内長野市・東大阪市）は中間の3点としています。

score = 3 − (支出流出入率(%) − (−5.6)) / 6

小規模自治体補正について

可住地面積当たりの施設密度も、可住地面積が小さい市町村では施設1件の増減で値が大きく振れます（例：可住地面積4km²の忠岡町では診療所1件で密度が25施設/100km²動く）。そこで医療・学校の2指標には、可住地面積を母数とした信頼度加重平均（縮小推定）をかけ、面積が小さいほど大阪府全体の密度に近づけています。可住地面積の大きい市（大阪市・堺市など）はほぼ元の値のままです。

補正後の密度 = (自市町村の密度 × 可住地面積 + 大阪府全体の密度 × K) / (可住地面積 + K) K：期待施設数が5件になる可住地面積（指標ごとに固定値）
指標母数大阪府全体の密度K
医療への行きにくさ可住地面積665.4 施設/100km²0.75 km²
学校への通いにくさ可住地面積74.1 校/100km²6.74 km²
!

スコアに含めなかった指標。「介護のうけやすさ」（高齢者当たりの施設定員）は、広域から利用者を受け入れる大規模な特別養護老人ホームが小規模町村に1つあるだけで数値が跳ね上がり、その町の住民が受けやすいことを意味しないため、スコアから外しカルテの参考値（介護施設定員／高齢者千人）としてのみ表示しています。「文化・生きがい施設」（図書館数）は大阪市・堺市以外ほぼ全市町村で0〜3館しかなく、統計として市町村間の比較に耐えないため外しました。

治安・防犯についても検討しましたが、e-Stat上のデータが2005年で更新停止しており、大阪府警の統計ページも本システムからは取得できなかったため、住民目線マップの指標には含めていません。

「地元で買えない度」（支出流出入率）は施設密度ではなく経済指標のため、小規模自治体補正の対象外です。

4 · Composite score

総合スコアの算出

各マップの「総合」表示やカルテのレーダーチャートで使う総合スコアは、それぞれの指標群の単純平均です。重み付けはしていません。「空き家」がデータなしの5町村は、残り7指標の平均を総合スコアとします。

地域課題マップ 総合スコア = (人口減少 + 高齢化 + 空き家 + 公共交通 + 地域コミュニティ + 担い手不足 + 防災 + DX) / 8 住民目線マップ 総合スコア = (買い物の不便さ + 医療への行きにくさ + 学校への通いにくさ + 地元で買えない度) / 4
5 · Caution

利用上の注意

!

地域課題マップの8指標・住民目線マップの4指標はすべて、その課題に対応する公的統計を直接スコア化しています。推定値による代用はどの指標でも行っていません。ただし「公共交通」は自家用車の利用率という住民の行動から測った指標である点に注意してください。自家用車の利用には公共交通の便以外の要因（勤め先の位置、世帯の所得、駐車場の有無など）も影響します。また対象は通勤・通学者であり、通勤も通学もしていない住民（高齢者など）の移動手段は含みません。

当初は国土交通省の定義（鉄道駅1km圏・バス停300m圏の外を公共交通空白地域とする）に沿って空白地域の人口割合を算出することも検討しましたが、国土数値情報のバス停留所データに事業者単位の欠落があり（忠岡町・高石市・柏原市などでバス停が0〜数件しか収録されていない）、市町村間の比較に使える精度がなかったため採用していません。鉄道駅のみのカバー率は駅位置データが完全なため、カルテに参考値として表示しています（ただし高槻市のようにバス網で支えられている市では低く出ます）。

また「防災」は土砂災害警戒区域数に基づくもので、洪水・高潮・地震などの他の災害リスクは含みません。「DX」は総務省調査の「導入しているか」「オンライン化しているか」を数えたもので、導入したAIがどの業務でどれだけ使われているか、オンライン申請が実際にどれだけ使われているかまでは測っていません。またAI・RPA・生成AIの調査結果は導入団体の一覧形式のため、一覧に掲載がない団体を「未導入」として扱っています（未回答の団体を含む可能性があります）。「空き家」は能勢町・田尻町・岬町・太子町・千早赤阪村の5町村で調査結果が未公表のため、地図・カルテ・分析レポートのいずれでも「データなし」として扱い、推定値による代用はしていません。本ツールはベータ版で、指標の選び方・算出方法は利用者の意見を踏まえて今後変更することがあります。各指標は個別の統計を組み合わせた大阪府市町村局振興課によるスコア化であり、国や大阪府による公式な評価結果ではありません。個別市町村の政策判断に用いる際は、現場の実態確認や関連部署へのヒアリングと合わせて利用してください。
