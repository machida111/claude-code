データ更新ツール

「地域課題分析カルテ」のHTMLに入っている市町村の統計値を、Excelで直して入れ替えるためのツールです。インターネット接続やプログラムは要りません。元のHTMLファイルは書き換えず、新しいHTMLファイルを保存します。手順の詳細は保守マニュアルの「年次のデータ更新」を見てください。

1今の「地域課題分析カルテ」のHTMLファイルを選ぶ

2今のデータをCSVで保存し、Excelで直す

ボタンを押すと、43市町村の統計値が1つの表（CSV）で保存されます。Excelで開き、変わった数値だけを直して、CSV形式のまま上書き保存してください（「CSV UTF-8」「CSV（コンマ区切り）」のどちらでも構いません）。

・1行目の見出しと「市町村ID」「市町村名」「自治体コード」の列は変えないでください（行の並べ替えは構いません）。自治体コードは、e-Statなどの表と照らし合わせるときに使います。
・空欄は「データなし」になります。空欄にしてよいのは、空き家率・支出流出入率・業種別事業所数（秘匿）だけです。推定値や中間値で埋めないでください。
・業種別事業所数の24マスがすべて空欄の市町村は「RESASで非公開」として扱います。

CSVの各列の意味（単位・空欄の可否）

3直したCSVを選ぶ（数値を変えない場合は飛ばしてよい）

4画面に出る年次と、今回の更新メモ

統計を新しい年のものに差し替えた場合は、その項目の年次も直してください（地図の「判定根拠」やカルテに表示されます）。「指標の計算方法」画面の説明文にある年次や例示の数値は自動では変わらないため、保守マニュアルの手順で直してください。

5新しいHTMLを保存する

保存したファイルをブラウザで開き、保守マニュアルの「更新後の確認」の項目を確かめてから、共有フォルダの元のファイルと入れ替えてください。元のファイルは念のため「旧版」フォルダに残してください。
